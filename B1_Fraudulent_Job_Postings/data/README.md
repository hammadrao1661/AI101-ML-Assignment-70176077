# Real or Fake Job Postings (EMSCAD) Dataset

Kaggle: `shivamb/real-or-fake-fake-jobposting-prediction` / HuggingFace: `james-burton/fake_job_postings2`
Samples: 17,880 postings. Target: fraudulent (0 = Real, 1 = Fake/Fraud).
Features: Title, description, requirements, employment type, company logo flag, etc.
