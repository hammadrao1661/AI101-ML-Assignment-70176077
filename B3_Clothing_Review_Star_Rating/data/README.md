# Women's E-Commerce Clothing Reviews Dataset

Kaggle: `nicapotato/womens-ecommerce-clothing-reviews` / HuggingFace: `saattrupdan/womens-clothing-ecommerce-reviews`
Samples: 23,486 reviews.
Target: Rating (1-5 stars, heavily skewed towards 5).
Leakage rule: Recommended IND is strictly excluded from input features.
