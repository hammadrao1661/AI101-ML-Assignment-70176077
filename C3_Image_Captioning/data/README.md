# Flickr8k Dataset

Kaggle: `adityajn105/flickr8k` / Hugging Face: `intro/flickr8k`
Samples: 8,091 images with 5 reference captions each (40,455 captions).
Split: 6,000 train, 1,000 validation, 1,000 test images.
Encoder: Frozen ImageNet-pretrained ResNet-50.
Decoder: LSTM merge architecture and attention-guided variant.
